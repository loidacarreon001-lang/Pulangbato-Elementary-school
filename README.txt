THE HILLTOP — Pulangbato Elementary School Online Publication

HOW TO PREVIEW
1. Extract the ZIP file to a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. Internet connection is needed for Google Fonts and sample Unsplash photos. The logo is stored locally in assets/.

FEATURES
- Responsive home page, Feature Stories, Editorial Cartooning, and About pages.
- Sample placeholder stories and editorial cartoons.
- Demo admin CMS to add, edit, and delete articles and cartoons.
- Content saved in the browser's localStorage.
- Export/import content as JSON for simple backup and transfer.
- No payments or unnecessary user forms.

IMPORTANT DEPLOYMENT NOTES
This is a front-end prototype for review and demonstration. The admin page is not protected by login and localStorage is specific to the browser/device. Do not publish sensitive information. Before using it as a public production website, add a secure backend, authentication/roles, image upload/storage, backups, and moderation workflow. Replace placeholder photos and sample stories with school-approved content. For best PWA installation/offline support, add a web app manifest and service worker and host the site over HTTPS.
